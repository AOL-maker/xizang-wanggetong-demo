# 西藏网格通 APP 交互原型｜离线交付版

版本日期：2026-11-04  
版本类型：纯静态、免构建、免后端、免数据库、可离线运行

## 一、最快启动：直接双击

1. 完整解压 ZIP 文件，不能只在压缩包预览窗口中打开。
2. 进入解压后的文件夹。
3. 双击 \`index.html\`，或双击 \`双击打开_DEMO.cmd\`。
4. 使用 Chrome、Edge、Firefox 或 Safari 等现代浏览器打开。

该模式不需要安装 Python、Node.js、数据库或任何开发工具。

## 二、Python 本地 HTTP 服务

适用于电脑已安装 Python 3 的情况：

- Windows：双击 \`启动_Python_HTTP服务.cmd\`。
- 命令行：在本目录执行 \`python -m http.server 8080 --bind 127.0.0.1\`。
- 浏览器访问：\`http://127.0.0.1:8080/\`。

停止服务：关闭命令窗口，或在窗口中按 \`Ctrl+C\`。

## 三、Nginx 部署

1. 将本文件夹全部内容复制到 Nginx 的静态站点目录。
2. 参考 \`部署配置/nginx.conf.example\` 配置站点根目录。
3. 重载 Nginx 后访问配置的地址。

这是纯静态应用，不需要反向代理、接口服务或数据库。

## 四、IIS 部署

1. 在 IIS 中新建网站或虚拟目录。
2. 将本文件夹全部内容复制到网站物理路径。
3. 保留根目录中的 \`web.config\`。
4. 确保 Windows 功能中的“IIS 静态内容”已启用。

## 五、演示登录

- 可按登录页提示使用本机号码、短信、面容等模拟入口。
- 账号密码演示：账号 \`XZ001028\`，密码 \`123456\`。
- 所有业务数据均为本地模拟数据，不会连接生产系统或提交真实业务。

## 六、运行边界

- 不依赖后端服务、数据库、Node.js、npm 或互联网。
- 角色切换、页面导航、增删改、筛选、工单流转等交互均在浏览器本地完成。
- 浏览器本地数据保存在 LocalStorage 中；清除浏览器站点数据后将恢复初始演示数据。
- 建议使用 375px 左右的移动端视口，桌面浏览器会自动显示手机宽度效果。

## 七、文件完整性

\`SHA256SUMS.txt\` 记录交付文件的 SHA-256 校验值。复制或传输后可据此核验文件未损坏。

## 八、AI 经营报告页（日报 / 周报 / 月报）

入口：工作台「AI 日报 / 周报 / 月报」卡片 →「查看 AI 日报与工作建议」。页面为应用内原生报告页，数据来自本机演示业务数据与报告快照。

页面结构（网格长）：

- **头部**：标题为「网格名 · 周期」（如「拉萨城关综合网格·日报」），右侧「报告记录」；第二行左侧为周期下拉（日报 / 周报 / 月报），右侧为「‹ 日期 ›」步进，可按日期、周、月切换同一视图。
- **智能晨会简报**：进入页面自动生成并保存报告快照（原「生成报告」按钮变为「更新报告」），下方为「网格长晨会简报」当日重点三件事。
- **整体经营情况**：12 项经营指标，一行三个紧凑排列，每卡显示完成值 / 目标值、缺口或达标标记、进度条与时间进度；指标缺口类指标卡片以浅橙底色提示。
- **AI 识别异常指标**：仅列出指标维度的异常（完成率缺口、保有率下滑、日必达未达、考核得分落后等），按 P0 高风险排序，逐条可「确认分工」；工单、任务类事项归入下方「团队未完成事项及重点工作」，两类不再混排。
- **AI 晨会发言框架**：进入页面即按当前报告快照自动生成「完成情况 / 主要问题 / 工作安排」三段内容，卡片默认收起，点击标题展开；内容可编辑、可重新生成、可保存。

周报 / 月报沿用同一骨架，指标、异常与发言框架随周期口径自动切换。

> `report.html` 为早期独立原型页，保留但不作为入口，可单独打开预览。
